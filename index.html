🛠️ Step-by-Step Guide

Step 1: Fork Your Chosen Game

  1. Log into your GitHub account.
  2. Navigate to your leader's template repository for the game you want to build.
  3. Click the Fork button in the top-right corner to save your own copy.

Step 2: Publish to GitHub Pages (Go Live!)

  1. Inside your repository, click the Settings tab at the top.
  2. On the left sidebar, click Pages.
  3. Under Build and deployment, change the branch from None to main (or master) and click Save.
  4. Wait ~60 seconds, refresh the page, and open your new live game link!

Step 3: Hack the Code & Add a Theme

  1. Go back to the Code tab and click on index.html, then click the Pencil icon to edit.
  2. Scroll down to the 🛠️ SCOUT HACKER ZONE near the top.
  3. Change game speed, timer limits, or paste image links into backgroundImageUrl and targetImageUrl.
  4. Click green Commit changes... to save!

🌟 Advanced Hacker Guide: Adding a "Play Again" Button

Want to let players restart the game without refreshing the page? Follow these steps to add a restart button when the 60-second timer hits zero!

1. Add this HTML button just below your game canvas:

<div style="margin-top: 15px;">
    <button id="restartBtn" style="padding: 10px 20px; font-size: 16px; font-weight: bold; background-color: #4CAF50; color: white; border: none; border-radius: 5px; cursor: pointer; display: none;">🔄 Play Again</button>
</div>

2. Add this JavaScript function inside your <script> tag:

const restartBtn = document.getElementById("restartBtn");

function restartGame() {
    score = 0;
    timeLeft = gameDuration;
    gameIsRunning = true;
    scoreDisplay.innerText = score;
    timerDisplay.innerText = timeLeft;
    restartBtn.style.display = "none"; // Hide button while playing

    // Restart your game loops / timers here!
}

restartBtn.addEventListener("click", restartGame);

Tip: When time runs out (`timeLeft <= 0`), make the button pop up by setting `restartBtn.style.display = "inline-block";`!

🎨 Where to Find Free Theme Images

To make your game look awesome, follow these rules when searching online:

  • Check the extension: Image URLs must end in .png or .jpg.
  • Transparent Backgrounds: For game characters or targets, use .png files with clear backgrounds so they don't look like boring square blocks.
  • Google Images Tip: Search for an icon (e.g., "airplane icon png"), click Tools > Color > Transparent to find clean cutouts.
  • Copy the Right Link: Right-click the image and select "Copy image address" (do not copy the browser tab URL!).
